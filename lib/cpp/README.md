# RadixIP C++ Engine (via C-ABI)

The C++ bindings for RadixIP use the C-ABI (Application Binary Interface) generated by the underlying Rust engine. This provides near-native performance for legacy C++ systems without sacrificing memory safety.

## Architecture

1. The Rust core compiles into a shared dynamic library (`.so`, `.dll`, or `.dylib`) exporting stable C symbols.
2. The `radixip.h` header maps these symbols.
3. The C++ class `RadixEngine` provides a modern RAII wrapper around the raw pointers to prevent memory leaks.

## Requirements

- A C++11 (or newer) compiler (GCC, Clang, MSVC)
- The compiled `libradixip_rs` shared library from `lib/rust/target/release/`

## Usage

```cpp
#include <iostream>
#include "radixip.hpp" // High-level C++ wrapper

int main() {
    try {
        // Initialize the engine (automatically handles the raw pointer)
        radixip::RadixEngine engine;

        // Insert a route
        radixip::Metadata meta;
        meta.value = "allow";
        // You can use a std::map for attributes if you expand the C++ wrapper
        
        if (!engine.insert("10.0.0.0/8", meta)) {
            std::cerr << "Failed to insert route!" << std::endl;
            return 1;
        }

        // Lookup
        radixip::Metadata result;
        if (engine.lookup("10.1.2.3", result)) {
            std::cout << "Match! Action: " << result.value << std::endl;
        } else {
            std::cout << "No match." << std::endl;
        }

    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << std::endl;
        return 1;
    }

    // Engine is automatically cleaned up by the destructor (RAII)
    return 0;
}
```

## Compilation

Link against the Rust shared library:

```bash
g++ -std=c++11 -o demo main.cpp -L../rust/target/release -lradixip_rs
./demo
```
